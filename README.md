# DevToolkit Hub

Подборка утилит для разработчиков среднего уровня: JSON, Base64, параметры URL, генераторы UUID и паролей, конвертер цветов и Markdown preview.

## Что внутри

- JSON formatter / minifier
- Base64 encode / decode
- Разбор query-параметров URL
- Генератор паролей
- Генератор UUID v4
- HEX / RGB / HSL converter
- Предпросмотр Markdown
- Автосохранение в локальном хранилище браузера

## Запуск

Откройте файл `index.html` в браузере. Никакой установки и сервера не требуется.

Для локального сервера можно запустить:

```powershell
cd C:\Users\bogbq\Desktop\dev-toolkit-hub
py -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```
